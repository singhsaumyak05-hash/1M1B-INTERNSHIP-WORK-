# 1M1B-INTERNSHIP-WORK-
The **AI-Based Smart Waste Management System** is a sustainability-focused solution designed to improve waste segregation and responsible disposal. The system uses **Artificial Intelligence and Computer Vision** to identify different types of waste from an uploaded image or captured photo. Based on the detected item, it classifies the waste into categories such as **wet waste, dry waste, recyclable waste, e-waste, or hazardous waste** and recommends the appropriate disposal method.

The project aims to reduce incorrect waste segregation, increase recycling, and minimize the amount of waste sent to landfills. A simple and interactive interface allows users to scan waste items, view the classification result, and learn proper disposal practices. The system can also track users' waste-management activities and display environmental impact through points, statistics, and sustainability tips.

By combining **AI, technology, and environmental awareness**, the project encourages individuals and communities to adopt responsible waste-management habits and supports **SDG 11, SDG 12, and SDG 13**
